# 매출의 이면 — 숨은 수익성·회수 리스크 진단

B2B 크리에이터 마케팅 대행사의 결제 데이터(7개 시트)를 통합해, **매출 지표에 가려진 실질 수익성과 채권 회수 리스크**를 진단한 데이터 분석 프로젝트입니다.

🔗 **[인터랙티브 대시보드 보기](https://statuesque-tarsier-977d2b.netlify.app/)**

---

## 1. 문제 정의

매출은 크지만 "실제로 남는 돈"과 "제때 들어오는 돈"은 별개입니다.
이 프로젝트는 다음 세 가지 질문에 데이터로 답합니다.

1. 매출에서 통과성 비용·원가를 걷어내면 실질 수익성은 얼마인가?
2. 매출이 큰 고객이 정말 좋은 고객인가?
3. 직접 관리하는 전속 크리에이터가 외주보다 더 남는가?

## 3. 분석 파이프라인

```
① 데이터 모델링      7개 시트 → 계약ID·광고주ID·크리에이터ID 조인 → 마스터 테이블
                     조인 전후 행수 검증 (청구 1,349건 → 1,349건, 누락·중복 0)
         ↓
② 정제 & KPI 산출    날짜 타입 변환 · 수금지연일 · CPV · 실질 공헌이익률
         ↓
③ 심층 EDA          고객 축 / 크리에이터 축 / 채권 축 3개 관점 교차 분석
         ↓
④ 시각화 & 대시보드   차트 3종 → 단일 HTML 대시보드 + 액션 플랜
```

### 핵심 KPI 정의

| 지표 | 정의 |
|---|---|
| 실질 공헌이익률 | `(매출 − 정산원가 − 매체집행액) ÷ 매출` |
| 수금지연일 | `입금일 − 입금예정일` (입금 완료 건만 집계) |
| CPV | `편당매출배분 ÷ 조회수` (조회수 0 건은 `np.where`로 제외) |

### 결측치 처리 원칙

- **입금일 결측을 0·예정일로 채우지 않음** → 채우면 미수 건이 '정상 수금'으로 왜곡됨. 지연 계산에서 제외하고 입금상태로 별도 집계.
- 외주 건의 다수 결측 컬럼은 임의 보간 없이 "해당 없음"으로 분리 처리.

## 4. 주요 발견

### ① 매출 ≠ 남는 돈

매출 약 **245억** 중 실질 공헌이익은 **21.5%(약 52.8억)**.
매체 통과분(약 53.6억, 매출의 21.8%)과 제작 원가(약 139.6억)가 빠지기 때문입니다.

### ② 큰 고객의 함정

- 대형(S1) 고객이 매출의 **47%(약 116억)** 를 차지하지만, 수금 지연(+0.90일)과 대손(약 0.82억)이 가장 집중됨
- 대형의 평균 결제조건은 **50.6일로 오히려 가장 짧음** (중견 54.1일, 중소 51.3일)
- → "결제조건이 길어서 늦는다"는 통념과 반대. 조건이 아닌 **실질 회수 리스크**의 문제

### ③ 전속의 함정

- 전속 크리에이터가 이익의 **60%(약 60억)** 를 만드는 주력
- 그러나 마진율은 **전속 39.2% < 외주 46.1%**
- → 전속의 높은 정산율이 원인으로 **추정**되나, 데이터만으로는 확정하지 못함 (추가 검증 필요)

### 종합

미수 + 대손 = **약 29.6억(청구액의 10.9%)** 이 회사 밖에 묶여 있으며, 대손 4건은 **전부 대형 우량 고객**에서 발생했습니다.

> 수치는 반올림 표기이므로 항목 간 합계가 정확히 일치하지 않을 수 있습니다.
